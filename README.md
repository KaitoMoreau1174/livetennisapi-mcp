# livetennisapi-mcp

MCP server for the Live Tennis API — give Claude, Cursor and other LLM agents real-time tennis scores, odds and model win-probability

## Usage

Import the module and call the exported helpers from your own code. The API is intentionally small so it is easy to embed.

## Installation

Clone the repository and install the dependencies with the package manager of your choice.

## Development

Run the test suite before sending changes and keep the public surface stable.
